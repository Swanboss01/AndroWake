# AndroWake

Logiciel Python (Tkinter) pour piloter un appareil Android via adb.

- Lancer : `python androwake.py`
- adb : téléchargé automatiquement (après confirmation) dans `platform-tools/`, à côté du programme.
- scrcpy (miroir d'écran) : téléchargé à la demande dans `scrcpy/`.
- Sur le téléphone : activer le débogage USB.
- Créer l'exécutable : `python build_exe.py` → `dist/AndroWake/AndroWake.exe`
